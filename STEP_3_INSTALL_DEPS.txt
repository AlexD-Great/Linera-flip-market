========================================
STEP 3: Install Build Dependencies
========================================

Copy and paste this SINGLE command into your Ubuntu terminal:

sudo apt update && sudo apt install -y build-essential pkg-config libssl-dev protobuf-compiler clang

(You'll be asked for your password - type it and press Enter)

This will install:
- build-essential (gcc, g++, make)
- pkg-config
- libssl-dev (OpenSSL development files)
- protobuf-compiler (Protocol Buffers compiler)
- clang (C/C++ compiler)

Time: ~2-5 minutes
